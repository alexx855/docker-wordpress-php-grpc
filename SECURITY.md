# Security Policy

## Reporting a Vulnerability

Please report potential vulnerabilities privately by emailing hello@alexpedersen.dev. Do not open a public issue until we have agreed on disclosure.

Include a concise description, affected version or commit, safe reproduction steps, impact, and any relevant logs or proof of concept. Never include credentials, tokens, private keys, seed phrases, or other sensitive data.

## Supported Versions

Security fixes are evaluated for the latest version on the default branch. Confirmed issues will be triaged privately and coordinated before public disclosure.
